# 크롬 웹스토어 등록 자료

개발자 대시보드(https://chrome.google.com/webstore/devconsole)에 그대로 붙여 넣을 내용입니다.
업로드 파일: `npm run package` → `dist/coding-daily-<버전>.zip`

## 0. 직접 해야 하는 것 (계정·결제라 대신 못 함)

1. 개발자 대시보드에 구글 계정으로 로그인 → 개발자 계약 동의 → **일회성 등록비 결제**(지금까지 미화 5달러, 결제 화면에서 확인)
2. 게시자 이름 입력, **연락 이메일 인증**(필수)
3. 아래 자료로 항목 만들기 → **검토 제출**. 보통 며칠, 길면 몇 주(새 개발자·새 확장은 더 걸릴 수 있음). 승인 후 30일 안에 게시

## 1. 패키지

- 새 항목 → zip 업로드: `dist/coding-daily-<버전>.zip`
- 업데이트할 때는 `manifest.json` 의 `version` 을 올리고 다시 `npm run package`

## 2. 스토어 등록정보(Store listing)

**이름** (manifest 에서 자동): 1일1코 - 하루에 알고리즘 하나

**요약** (manifest description, 132자 이내, 자동):
프로그래머스 코딩테스트 문제를 매일 하나씩 알림으로 추천하고, 제출 결과를 자동 감지해 복습·약점 분석까지 해 줍니다. (비공식)

**상세 설명**:

```
매일, 코딩테스트 단골 유형에서 프로그래머스 문제 하나를 골라 알려 드립니다.

■ 하루 한 문제 추천
- 구현·DFS/BFS·완전탐색·DP·그리디·문자열·해시·스택/큐·정렬·힙·이분탐색·그래프·투포인터·수학, 14개 유형을 출제 비중대로 돌려가며 추천
- 고득점 Kit → 카카오·PCCP 기출 → 연습문제 순으로, 이미 푼 문제는 빼고 추천
- 유형별 난이도 자동 조절: 깔끔하게 풀면 한 단계 위로, 막히면 한 단계 아래로

■ 알림
- 정한 시각마다(기본 오전 10시·오후 2시·5시·8시, 바꿀 수 있음) 오늘의 문제 알림
- 알림은 하루 내내 같은 문제로 오고, 풀면 그날 남은 알림은 오지 않음 ('오늘은 그만 알림'도 가능)
- 툴바 아이콘 배지로 오늘 남은 문제 수 표시

■ 풀이 자동 감지
- 문제 페이지에서 '제출 후 채점하기' 결과(정답/오답)를 자동으로 기록
- 로그인한 프로그래머스 계정의 '해결한 문제'를 가져와 다른 기기에서 푼 문제도 반영
- 자동 감지가 안 될 때는 '풀었어요'로 직접 체크

■ 못 푼 문제는 며칠 뒤 다시
- 추천받은 날 못 풀면 3일 뒤(설정 가능) 복습으로 다시 추천, 풀 때까지 반복

■ 기록과 약점 분석
- 날짜·유형·난이도·오답 수·풀이 시간 기록, 1년치 풀이 잔디
- 유형별 약점 지수(0~100), 약한 유형 TOP 3와 공부 팁
- 약한 유형은 추천에 더 자주 등장

■ 개인정보
- 모든 기록은 내 브라우저에만 저장되고 외부 서버로 보내지 않습니다.
- 풀이 코드·비밀번호는 읽거나 저장하지 않습니다.

※ 프로그래머스(㈜그렙)와 관련 없는 비공식 도구입니다.
```

**카테고리**: 교육(Education) — 없으면 생산성 > 도구
**언어**: 한국어

## 3. 개인정보 보호 관행(Privacy practices)

**단일 목적(Single purpose)**:
프로그래머스 코딩테스트 문제를 하루 한 문제씩 추천하고, 풀이 결과를 기록해 복습 알림과 약점 분석을 제공하는 학습 도우미입니다.

**권한별 사유(Permission justification)**:

| 권한 | 사유 |
| --- | --- |
| `storage` | 추천 문제, 풀이 기록, 설정을 사용자 브라우저에 저장합니다. |
| `alarms` | 사용자가 정한 알림 시각과 자정의 날짜 넘김 처리를 예약합니다. |
| `notifications` | 오늘의 문제(못 풀었으면 같은 문제로 다시)와 복습 문제를 데스크톱 알림으로 보여 줍니다. |
| 호스트 권한 `https://school.programmers.co.kr/*` | 프로그래머스 문제 페이지에서 채점 결과(정답/오답)를 감지하고, 로그인한 사용자가 해결한 문제 목록을 가져옵니다. 다른 사이트에는 접근하지 않습니다. |

**원격 코드(Remote code)**: 아니요, 원격 코드를 사용하지 않습니다(모든 코드가 패키지에 포함).

**데이터 사용 공개(Data usage)** — 브라우저 안에만 저장해도 공개 대상이므로 아래를 체크:
- [x] 웹 기록(Web history): 프로그래머스 문제 페이지를 연 시각
- [x] 사용자 활동(User activity): 문제 제출 결과(정답/오답)
- [x] 웹사이트 콘텐츠(Website content): 문제 번호·제목, 해결한 문제 목록
- 나머지(개인 식별 정보, 건강, 금융, 인증 정보, 개인 커뮤니케이션, 위치)는 체크하지 않음

인증(Certify) 3개 모두 체크:
- 승인된 용도 외에 제3자에게 판매·전송하지 않음
- 단일 목적과 무관한 용도로 사용·전송하지 않음
- 신용도 판단·대출 목적으로 사용·전송하지 않음

**개인정보처리방침 URL**: `store/PRIVACY.md` 를 공개된 주소에 올린 링크
(예: GitHub 공개 저장소 → `https://github.com/gggeunyoung/programmers-daily/blob/main/store/PRIVACY.md`)

## 4. 배포(Distribution)

- **공개(Public)**: 스토어 검색에 노출. 누구나 '크롬에 추가'
- **일부 공개(Unlisted)**: 검색에는 안 나오고 **링크를 아는 사람만** 설치 — 스터디원·친구에게 먼저 나눌 때 추천
- 비공개(Private): 지정한 테스터만
- 지역: 전체(또는 대한민국)
- 어떤 공개 범위든 검토 절차는 같다
